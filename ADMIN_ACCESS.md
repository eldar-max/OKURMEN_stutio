# 🔐 Доступ к Админ-Панели ОКУРМЭН

## Как настроить доступ администратора

### Шаг 1: Укажите ваш email

Откройте файл: `src/pages/AdminDashboard.jsx`

Найдите строку (около строки 23):
```javascript
const adminEmail = 'your-email@gmail.com'; // Замените на ваш реальный email
```

Замените `'your-email@gmail.com'` на ваш **реальный Google email**, который вы используете для входа.

**Пример:**
```javascript
const adminEmail = 'kika0@gmail.com'; // Ваш email
```

### Шаг 2: Обновите Login.jsx

Откройте файл: `src/pages/Login.jsx`

Найдите строку (около строки 59):
```javascript
const adminEmail = 'your-email@gmail.com';
```

Замените на **тот же email**, что указали в AdminDashboard.jsx

### Шаг 3: Войдите через Google

1. Откройте сайт: http://localhost:5173
2. Нажмите **"Войти"**
3. Нажмите **"Войти через Google"**
4. Выберите ваш Google аккаунт
5. Вы автоматически попадете в админ-панель по адресу: http://localhost:5173/admin

## Прямой доступ к админке

После того как вы один раз вошли через Google, вы можете перейти напрямую:
```
http://localhost:5173/admin
```

## Что есть в админ-панели?

### 📊 Обзор (Overview)
- Статистика: студенты, преподаватели, курсы, доход
- Последние зарегистрированные пользователи
- Последние платежи

### 👥 Пользователи (Users)
- Просмотр всех пользователей
- Добавление новых пользователей
- Редактирование информации
- Удаление пользователей
- Блокировка/разблокировка

### 📚 Курсы (Courses)
- Просмотр всех курсов
- Добавление новых курсов
- Редактирование курсов
- Удаление курсов
- Управление статусом (активен/неактивен)

### 💰 Платежи (Payments)
- Просмотр всех транзакций
- Подтверждение платежей
- Экспорт в Excel
- Фильтрация по статусу

## Безопасность

⚠️ **ВАЖНО:**
- Только пользователь с указанным email может войти в админку
- Все остальные будут перенаправлены на главную страницу с сообщением об отказе в доступе
- Не делитесь своим admin email публично

## Интеграция с Backend

Сейчас админка использует **mock data** (тестовые данные).

Ваш backend партнер должен:
1. Подключить Firebase Firestore для хранения данных
2. Создать коллекции: `users`, `courses`, `payments`
3. Заменить mock data на реальные запросы к Firebase
4. Добавить формы для CRUD операций (Create, Read, Update, Delete)
